# Self-hosted fonts

Only these three font files are shipped; no external font service is contacted.

- `InterVariable.woff2`: Inter v4.1, normal variable face, from
  [rsms/inter](https://github.com/rsms/inter/blob/v4.1/docs/font-files/InterVariable.woff2).
  SIL Open Font License: `Inter-OFL.txt`.
- `Geist.woff2`: normal variable sans face (one file, 69,760 bytes), from
  [vercel/geist-font](https://github.com/vercel/geist-font/blob/b5d164a0c066c2c9bfcd5ab65dd8244551f0ac06/fonts/Geist/webfonts/Geist%5Bwght%5D.woff2),
  pinned at `b5d164a0c066c2c9bfcd5ab65dd8244551f0ac06` (same revision as Mono).
  SIL Open Font License: `OFL.txt` (covers both Geist families).
- `GeistMono.woff2`: normal variable face, from
  [vercel/geist-font](https://github.com/vercel/geist-font/blob/b5d164a0c066c2c9bfcd5ab65dd8244551f0ac06/fonts/GeistMono/webfonts/GeistMono%5Bwght%5D.woff2),
  pinned at `b5d164a0c066c2c9bfcd5ab65dd8244551f0ac06`.
  SIL Open Font License: `OFL.txt`.

Keep upstream notices with the files when updating. These are font licenses,
