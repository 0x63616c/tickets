# Issue #15 visual audit

Before images are the real routes on `origin/main` at
`da96506186bdfe9f182dcc2fd9b5b314a73b7c7a` (#9 merged), built in the temporary
`/tmp/tickets-15-main` worktree. The worktree was removed after capture. Target
images are the **separate** `/design*` fixtures from that same commit; they are
not presented as the before state.

After images use the #15 branch. Both runs use the same API seed in
`xtask/src/polish.rs`, an isolated local Worker/D1, 1440×900 desktop and 390×900
mobile, dark mode, DPR 1, and loaded Inter/Geist fonts. Tickets use the design
examples, persisted through the real API. IDs and dates are generated by the
local database. The token screenshot contains metadata only; generated
credentials stay under ignored `target/` and are never captured.

`projects-preview-*` is explicitly the existing `/design/projects` preview.
There is no real Projects management route on this base: its integration belongs
to #10, after #15 in the requested dependency order. The fixture project creation
flow is exercised by `design-check`; the real ticket creation/move/label/dependency
flows are exercised by the board, list, and detail checks. This pass adds no
project CRUD, live transport, API changes, or deployment.

## Audit

| Screen | Issue found | Fix / result |
| --- | --- | --- |
| Kanban | Tabs separated across the page; unused review column squeezed cards; minimum width 216px; count included hidden canceled tickets | Adjacent view tabs, fixture's four default columns, populated review column, all six statuses in native selects, 240px minimum, contained horizontal scroll, visible-status count |
| List | Titles started at different positions on mobile; button padding shifted text; icons had no hover feedback | Fixed 56px key slot, zero title-button padding, ellipsis with full-title tooltip, shared focus/hover feedback; 36px rows retained |
| Ticket detail | Tall comments/editor pushed submit below viewport; repeated comment label; empty assignee copy; awkward mobile dependency wrapping | Compact comment controls, accessible label plus useful placeholder, neutral Avatar, aligned mobile dependency grid; submit fits at 900px |
| Create dialog | Unlabelled status text, no Cancel action, extra empty error spacing | Explicit status/icon, Cancel, shared fields and chevron, empty error nodes collapsed; focus returns to opener |
| Command palette | Unbounded result area, blank no-results state, selection could silently do nothing off the board/list | Scrollable 36px rows, explicit empty state, ticket links from every real route, keyboard focus, Escape restoration, no nested shortcut dialogs |
| Login | Separate controls had inconsistent heights/hover; failure copy asked the user to sign in again | Shared 32px controls and focus ring, stable error space, clear incorrect-credentials message; password cleared after failure |
| API tokens/settings | Raw timestamps, separate control styling, cramped mobile inline form, actionable controls while signed out | Bordered settings form with footer action, shared controls, concise dates with full timestamp tooltips, wrapping metadata, signed-out Sign in link |
| Empty project | Blank board with no direct explanation/action | Fixture EmptyState and New ticket action, four dashed column actions, no irrelevant filters |
| Empty workspace | API implementation instructions and disabled empty columns | Concise No projects yet state; project UI remains #10 |
| Empty list/search | Passive instruction text / blank palette | Visible recovery actions and no-results copy |
| Projects preview | Page already matched the reference; workspace switcher implied an unavailable mode | Retain restrained project rows; home link replaces inert workspace switcher; explicit preview boundary |
| Mobile shell | Missing expanded state, outside dismissal, and focus containment; extra document height | 240px sidebar, labelled toggle, scrim/Escape dismissal, focus return/Tab containment, viewport-aware main height |

## Reproduce

Set `CHROME_BIN` to the managed environment's installed headless shell:
`/home/box/.cache/ms-playwright/chromium_headless_shell-1248/chrome-headless-shell-linux64/chrome-headless-shell`.
Run `cargo xtask polish-check`. The task handles local migrations, randomized
credentials, API seed, Chromium, assertions, captures, and server cleanup. Trunk
runs with `NO_COLOR=true` through xtask. Use `TICKETS_SCREENSHOT_DIR` to capture
without replacing committed evidence. For before captures only, point
`TICKETS_BEFORE_ASSETS` to the base worktree's release `crates/web/dist` directory.
