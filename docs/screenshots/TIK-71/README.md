# TIK-71 evidence

`before-home*.png` are the approved TIK-65 after screenshots, retained as the
current Home baseline. `after-home*.png` are generated by `perf-browser-check`
against isolated local D1 with synthetic project/ticket data. The fixtures differ;
this PR changes data loading and recovery, not layout, styles or tokens.
`requests.json` records browser endpoint paths only, without credentials.

See `docs/performance/TIK-71.md` for measured D1 rows, caller audit and CPU limits.
The first-run, Home loading, and Board/List loading checks separately verify that
refreshes retain content and do not replay the initial skeleton/reveal.
